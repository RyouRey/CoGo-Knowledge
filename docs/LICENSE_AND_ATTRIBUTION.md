# License and attribution status

This repository package does not include a `LICENSE` file, and this rebuild intentionally does not choose a license on the owner's behalf. A public GitHub repository should not be assumed to be open-source licensed merely because its contents are viewable.

The knowledge base includes research synthesis, links to official CoGo/App Dev for All pages, references to public source repositories, and historical code examples. Before adding a license or redistributing third-party material, review the applicable upstream license and attribution requirements. Keep source URLs close to the claims and samples they support.

The absence of a license file is a repository-maintenance item for the owner to resolve if reuse permissions need to be explicit. This note is not legal advice.
