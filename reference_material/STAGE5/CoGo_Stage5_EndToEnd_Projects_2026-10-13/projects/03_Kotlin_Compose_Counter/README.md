# P3 — Kotlin Jetpack Compose Counter

## Goal
Practice a Compose screen, state updates, buttons and a simple reset action.

## Create in CoGo
- Project name: `ComposeCounter`
- Example package: `com.example.composecounter`
- Choose a Compose-enabled Kotlin template. Do not use a Views-only template.
- Keep generated Gradle files and Compose dependencies.
- Replace only the generated `MainActivity.kt`, adapting its package declaration.

## Build and test
- Wait for sync.
- Run the normal debug build/run first.
- Initial value must be 0; `+1` increments; Reset returns to 0.

## Troubleshooting
If `androidx.compose.*` or `MaterialTheme` is unresolved, stop and verify that the project was created from a Compose template and that its generated Gradle setup is intact. Do not add arbitrary dependency versions before checking the actual project.
